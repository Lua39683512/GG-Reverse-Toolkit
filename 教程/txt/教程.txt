逆向工具箱 v1.0.5

一、工具简介

逆向工具箱是一款基于 GameGuardian Lua 的辅助工具。

目前主要用于特征生成、搜索结果管理、保存列表管理、地址选择以及特征文件对比。

工具通过 GameGuardian 的悬浮按钮运行，不需要额外绘制悬浮窗口。

二、基本操作

运行脚本后，点击 GameGuardian 悬浮按钮即可打开工具主菜单。

主菜单：

1. 数值选择
2. 对比
3. 特征
4. 退出

三、数值选择

用于选择特征扫描的目标地址。

进入「数值选择」后，可以使用以下功能：

1. 搜索列表

读取 GameGuardian 当前搜索结果。

选择一个结果后，将其作为特征扫描的目标地址。

显示内容包括：

地址
数值
数据类型
内存范围

2. 保存列表

读取 GameGuardian 的保存列表。

选择一个项目后，将其作为特征扫描的目标地址。

显示内容包括：

名称
地址
数值
数据类型
内存范围

3. 地址

手动输入地址。

可以选择：

10 进制
16 进制

输入完成后，该地址将作为特征扫描的目标地址。

四、对比

用于对比两个特征文件。

需要选择：

文件1
文件2
输出文件名
输出文件保存位置

工具会逐行比较两个文件。

只有满足以下条件的行才会保留：

1. 两个文件对应行的 A[] 偏移量相同。
2. 两行中至少存在一个完全相同的「数值 + 数据类型」。

例如：

文件1：
A[-3]W,B

文件2：
A[-3]W,B

该行可以保留。

如果 A[] 偏移量不同，即使存在相同的数据，也不会保留。

输出结果会在匹配的 A[] 后面添加相同的数据类型。

例如：

A[-3]W,B

如果输出文件已经存在，工具会自动使用：

文件名(1)
文件名(2)
文件名(3)

依次避免覆盖原文件。

五、特征

进入「特征」后，可以使用：

1. 扫描
2. 设置

六、特征设置

进入「设置」后，可以设置：

1. 数据类型
2. 偏移量进制
3. 其它

七、数据类型

可以选择以下数据类型：

D = DWORD
F = FLOAT
E = DOUBLE
W = WORD
B = BYTE
Q = QWORD
X = XOR

默认情况下所有数据类型均为选中状态。

可以根据需要关闭不需要的数据类型。

八、偏移量进制

可以选择特征文件中的偏移量显示方式：

10
使用十进制显示偏移量。

例如：

A[-3]

16
使用十六进制显示偏移量。

例如：

A[-0x3]
A[0x10]

九、其它设置

可以设置：

特征距离
特征文件保存位置
特征文件名称

特征距离表示以目标地址为中心，向前和向后读取的地址范围。

例如：

特征距离 = 8

表示扫描：

目标地址 - 8
到
目标地址 + 8

共 17 个偏移位置。

设置会在当前脚本运行期间保留。

再次打开设置时，会自动使用上一次的设置作为默认值。

十、扫描

首先通过「数值选择」选择一个目标地址。

然后进入：

特征 → 扫描

工具会根据当前设置读取目标地址附近的数据，并生成特征文件。

例如目标地址为：

74A76FE039

特征距离为：

3

则会读取：

-3
-2
-1
0
+1
+2
+3

对应位置的数据。

生成的特征文件格式类似：

74A76FE036    -1D ; NaNF ; ...    A[-3]
74A76FE037    ...                  A[-2]
74A76FE038    ...                  A[-1]
74A76FE039    ...                  A[0]
74A76FE03A    ...                  A[1]

其中：

第一列 = 地址

第二列 = 数值及数据类型

第三列 = 相对于目标地址的偏移量

十一、数据类型标识

特征文件中的数据类型使用以下字母：

D = DWORD
F = FLOAT
E = DOUBLE
W = WORD
B = BYTE
Q = QWORD
X = XOR

例如：

123D

表示 DWORD 类型的 123。

1.5F

表示 FLOAT 类型的 1.5。

十二、文件保存

默认保存位置：

/sdcard/

默认文件名：

特征

如果文件已经存在，不会直接覆盖。

工具会自动生成：

特征
特征(1)
特征(2)
特征(3)

依次类推。

十三、菜单返回

除主菜单以外，大部分菜单都会自动提供：

回到主页

点击后返回主菜单。

退出功能用于结束工具脚本。

十四、使用流程示例

生成特征文件的基本流程：

1. 运行逆向工具箱。
2. 点击 GameGuardian 悬浮按钮。
3. 进入「数值选择」。
4. 从「搜索列表」「保存列表」或「地址」中选择目标地址。
5. 返回主菜单。
6. 进入「特征」。
7. 根据需要进入「设置」。
8. 选择数据类型。
9. 选择偏移量进制。
10. 设置特征距离和保存位置。
11. 进入「扫描」。
12. 等待扫描完成。
13. 在设置的目录中找到生成的特征文件。

十五、注意事项

1. 使用前请确保 GameGuardian 正常运行。
2. 「搜索列表」需要 GameGuardian 当前存在搜索结果。
3. 「保存列表」需要 GameGuardian 当前存在保存项目。
4. 手动输入地址时，请确认地址格式和进制选择正确。
5. 特征距离越大，需要读取的数据越多。
6. 输出文件存在时，工具会自动生成新的文件名，不会覆盖原文件。
7. 本工具目前主要面向 GameGuardian Lua 环境使用。
8. 不同 GameGuardian 版本或修改版可能存在兼容性差异。
9. 请在合法、合规的测试和研究环境中使用。
