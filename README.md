# GG-Reverse-Toolkit

一个用于 GameGuardian 的 Lua 逆向分析工具箱。

主要用于特征数据生成、搜索结果选择、保存列表选择、地址选择以及特征文件对比。

功能

数值选择

可以从以下来源选择目标地址：

- 搜索列表
- 保存列表
- 手动输入地址

搜索列表和保存列表会显示：

- 地址
- 数值
- 数据类型
- 内存范围

手动输入地址支持：

- 十进制
- 十六进制

特征

根据选定的目标地址读取附近内存数据，并生成特征文件。

支持的数据类型：

标识| GameGuardian 类型
"D"| DWORD
"F"| FLOAT
"E"| DOUBLE
"W"| WORD
"B"| BYTE
"Q"| QWORD
"X"| XOR

默认启用所有数据类型，可以在设置中选择需要的数据类型。

特征距离

可以设置扫描范围。

例如：

特征距离 = 8

将读取目标地址：

-8 ~ +8

范围内的数据。

偏移量进制

支持：

- 十进制
- 十六进制

例如十进制：

A[-3]
A[0]
A[8]

十六进制：

A[-0x3]
A[0x0]
A[0x8]

特征文件

生成的特征文件包含：

地址    数值及数据类型    偏移量

示例：

74A76FE039    -1D ; NaNF ; 4.77830972673648E-299E    A[-3]

其中：

- 第一列为地址
- 第二列为数值及数据类型
- 第三列为相对于目标地址的偏移量

如果输出文件已经存在，工具会自动生成新的文件名：

特征
特征(1)
特征(2)
特征(3)

不会直接覆盖已有文件。

文件对比

可以对两个特征文件进行逐行对比。

对比时会检查：

1. 两个文件对应行的 "A[]" 偏移量是否相同。
2. 对应行中是否存在至少一个完全相同的「数值 + 数据类型」。

只有同时满足条件的行才会保留。

例如：

文件1：
...    A[-3]

文件2：
...    A[-3]

并且两个文件中存在相同的：

123D

则该行会被保留。

对比结果会在对应的 "A[]" 后面添加匹配的数据类型，例如：

A[-3]W,B

如果同时匹配多个数据类型，则按照以下顺序输出：

D,F,E,W,B,Q,X

设置

数据类型

可以单独启用或关闭：

D
F
E
W
B
Q
X

默认全部启用。

偏移量进制

可以选择：

10
16

默认使用十进制。

其它

可以设置：

- 特征距离
- 特征文件保存位置
- 特征文件名称

设置窗口会保留上一次输入的内容，并作为下一次打开时的默认值。

运行方式

本工具使用 GameGuardian Lua 环境运行。

运行脚本后，通过 GameGuardian 的悬浮按钮打开工具菜单。

工具使用 GameGuardian 原生 UI 按钮：

gg.showUiButton()

并通过：

gg.isClickedUiButton()

检测按钮点击。

注意事项

- 本工具需要 GameGuardian Lua 环境。
- 不同 GameGuardian 版本或修改版可能存在兼容性差异。
- 手动输入地址时，请确认地址及进制选择正确。
- 特征距离越大，需要读取的数据越多。
- 生成文件时，如果目标文件已经存在，工具会自动使用新的文件名。
- 本项目主要用于合法的逆向分析、程序调试和研究用途。
