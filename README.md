# Reverse-Toolkit
一个用于GameGuardian的Lua逆向分析工具箱
## 特点
- 数值的各种排版尽可能还原GameGuardian
- 可以自定义特征扫描的数据类型,文件保存位置等
## 主要功能
### 特征扫描
扫描选中数值周围的数值,写入到文件
### 对比特征
对比选中的两个特征文件,把有效的特征写入到对比文件
## 下载教程
方法1
1. 下载`Reverse-Toolkit.lua`
2. 使用GameGuardian执行
方法2
1. 下载`下载.lua`
2. 使用GameGuardian执行
3. 找到脚本下载的文件
4. 使用GameGuardian执行
